MDKR RECORDS v0.5 / 프로필·칭호·추월 알림 업데이트

순서
1. SQL Editor에서 supabase_migration_v05.sql 전체 실행 (v0.4 먼저 설치 필수)
2. backend.js 와 styles.css만 기존 GitHub 저장소에 덮어쓰기
3. GitHub Desktop Commit / Push -> 배포 후 새로고침

기능
- Discord 로그인 뒤에도 닉네임을 덮어쓰지 않음
- 프로필 닉네임/소개/칭호 하나 장착
- 기본 흰색/에픽/특별 금색 칭호 카탈로그와 자동 해금 일부
- FC 악곡명 파란색, Lv.12 AP 금색 칭호
- 왕좌 교체 시 로그인 사용자 알림, 추월/탈환 이벤트 카운트
- 동일 세부 점수일 때 신규 승인 기록 우선 (제출시각 기준)

주의
- 기존 v0.4 rank view가 v0.5에서 교체됩니다. 적용 전에 Supabase 백업 권장.
- 왕좌 이력은 v0.5 설치 뒤 승인 건부터 기록합니다.
- 모든 업적의 조건이 구현된 것은 아닙니다. 추적 불가 조건은 잠금 유지됩니다.
- 인간승리: 추월 30회 중 각 이벤트별 1회 탈환으로 30건 해결.
- PEROPERO 직접 수여, 과거 기록 개선 횟수 업적은 다음 버전 지원.
- 기존 화면과 기본 자켓 data/ 폴더에는 손대지 않습니다.
- 기존 config.js와 다른 파일도 유지하세요.
